# What changed in Truffle

The newest version is at the top.

## 0.1.1 · 13/11/2026

- The automatic interface size fits the window too, so a small window is no longer drawn too big
- The Interface size slider changes the size when you let go, not while you drag it
- New Lyrics blur setting for the Now playing view (Settings > Appearance > Motion)
- Sliders only move with the left mouse button, so a right-click no longer changes the volume
- Song videos (Canvas) no longer smear into stripes when their frame size changes
- Home: playlist and mix covers are plain covers that lift on hover

- First public release
